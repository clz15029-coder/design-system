基本要素

すべてのデザインの土台になる決まりです。

Color

色は用途ごとに分けて並べています。使うのは意味のトークン（Surface / Text / Border / Accent）で、元の色（プリミティブ）は Token タブにあります。

Background（背景）

いちばん下の層です。ページ全体の地の色に使います。

Surface Primary
#FFFFFF
基本の背景
--waku-surface-primary

Surface（面）

背景の上に乗る面の色です。白と区別したいときに敷きます。

Surface Secondary
#F7F7F7
白の代わりに敷く面（表の見出し行など）
--waku-surface-secondary

Text（文字）

文字の色です。本文は黒、補助的な文字だけグレーを使います。

Text Primary
#000000
本文・見出しの文字
--waku-text-primary
Text Secondary
#757575
日付や補足の文字
--waku-text-secondary

Border（線）

区切り線や枠の色です。弱い線と強い線の2種類だけにします。

Border Default
#E0E0E0
弱い区切り線
--waku-border-default
Border Strong
#000000
強い線・枠
--waku-border-strong

Accent（印）

目印のためだけの色です。面積は小さく、文字色には使いません。

Accent
#00FF00
目印だけ（面と印）。文字色には使わない
--waku-accent

プリミティブは元の値そのもの。実際にコーディングで使うのは、意味のトークンの方です。

トークン名値使い道

コード

:root{
  /* 色：プリミティブ（元の色） */
  --waku-color-white:#FFFFFF;
  --waku-color-black:#000000;
  --waku-color-green:#00FF00;
  --waku-color-gray-50:#F7F7F7;
  --waku-color-gray-200:#E0E0E0;
  --waku-color-gray-500:#757575;

  /* 色：セマンティクス（意味の名前。使うのはこっち） */
  --waku-surface-primary:var(--waku-color-white);
  --waku-surface-secondary:var(--waku-color-gray-50);
  --waku-text-primary:var(--waku-color-black);
  --waku-text-secondary:var(--waku-color-gray-500);
  --waku-border-default:var(--waku-color-gray-200);
  --waku-border-strong:var(--waku-color-black);
  --waku-accent:var(--waku-color-green);
}

Color の使い方

配分の目安は、白（背景）がいちばん大きく、次に黒（文字と線）、グレーは補助、ビビットグリーンは面積を小さく「印」としてだけ使います。緑を本文の文字色には使いません。色を増やしたくなったら、まずグレーで足りないか考えます。

やってはいけない例：緑の大きな背景、色の数を増やす、影を重ねる、本文をグレーで書く（補助文字グレーは日付や注釈だけ）。

Text Style

書体は Noto Sans JP が基本です（どちらも Google Fonts）。Poppins は欧文の見出しだけに使い、本文中の英数字も Noto Sans JP で表示します。サイズは 12／14／16／24／32 の5段階（2026-11-05に Spindle 型へ変更）。本文まわりは細かく刻み（12／14／16）、見出しで跳ねます（24／32）。行間は本文で1.7倍が目安です。

ページタイトル
24px / Bold
セクション見出し
16px / Regular
本文です。カードのタイトルは、このサイズの太字で兼用します。
14px / Regular
少し小さな本文です。注釈や、密度の高いUIに使います。
12px / Regular
2026.11.05 日付やキャプションなどの補助テキスト

Corner Radius

角丸は「要素の短辺の長さ」で決めます。気分で変えないのがルールです。タグとボタンはピル型で統一します。

0
写真そのもの、区切り線
4
バッジ、小さいボタンなど（短辺 〜20px）
8
小さいカードなど（短辺 21〜64px）
16
作品カードなど（短辺 65px〜）
Pill
タグ・チップ、ボタン専用

角丸

トークン名値使い道
--waku-radius-none0写真そのもの、区切り線
--waku-radius-sm4pxバッジ、小さいボタンなど（短辺 〜20px）
--waku-radius-md8px小さいカードなど（短辺 21〜64px）
--waku-radius-lg16px作品カードなど（短辺 65px〜）
--waku-radius-pill999pxタグ・チップ、ボタン専用

コード

:root{
  /* 角丸 */
  --waku-radius-none:0;
  --waku-radius-sm:4px;
  --waku-radius-md:8px;
  --waku-radius-lg:16px;
  --waku-radius-pill:999px;
}

Shadow

基本は影なし（フラット）で、区切りは線と余白で付けます。例外として、画面の上に浮く要素（ポップアップや浮いたボタン）だけ、黒 #000000 の10%透過・右下にずれる・ぼかしなしの影を1種類だけ使います（ずれ：右4px／下8px）。ボタンはホバーのときだけこの影が付き、少し上に跳ね上がります（影自体は伸びません）。

浮いている要素のサンプル

影

トークン名値使い道
--waku-shadow-floating4px 8px 0 rgba(0,0,0,0.1)画面の上に浮く要素だけ（ポップアップ、ホバー時のボタン）

コード

:root{
  /* 影 */
  --waku-shadow-floating:4px 8px 0 rgba(0,0,0,0.1);
}

Spacing

余白の基本単位は8px。余白は8で割り切れる数字だけを使います。小さいパーツに限って、4で割り切れる数字（例：12px）も使えます。要素の中の余白は16、要素と要素の間は24、セクションの間は64が目安です。

Icons

塗り（面）のアイコンで統一します。形は丸みのあるものを選び、サイズは24pxが基本、小さい所は20px。色は黒が基本で、目立たせたい所だけビビットグリーンにします。
